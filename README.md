# 📖 مصحف ورش الشريف — رواية ورش عن نافع

تطبيق ويب تقدمي (**PWA**) متكامل لقراءة، استماع، وتسميع القرآن الكريم **برواية ورش عن نافع** من طريق الأزرق، بخط مجمع الملك فهد لطباعة المصحف الشريف، مع ميزة التزامن الصوتي كلمةً بكلمة ومصحح التلاوة التفاعلي.

---

## ✨ المميزات الرئيسية

### 1. النص المصحفي والخط العثماني الأصيل
* **رواية ورش عن نافع**: النص القرآني كاملاً بترقيم ورش المعتمد (**6,214 آية** بالعدّ المدني).
* **خط مجمع الملك فهد**: خط `KFGQPC Warsh Uthmanic Script` يدعم كافة علامات الضبط الخاصة بورش (النقط المدورة، علامات التقليل والإمالة، تسهيل الهمز ونقله).

### 2. التلاوة الصوتية المتزامنة كلمة بكلمة (Word-by-Word Sync)
* تظليل فوري ودقيق لكل كلمة يتلوها القارئ، مع معالجة دقيقة للبسملة وزوال أي إزاحة (Zero Décalage).
* إمكانية **النقر على أي كلمة** في المصحف ليقفز مشغل الصوت ويبدأ القارئ التلاوة من عندها مباشرة.
* نخبة من قراء ورش:
  * الشيخ **ياسين الجزائري** (تلاوة جزائرية برواية ورش).
  * الشيخ **إبراهيم الدوسري**.
  * الشيخ **عبد الباسط عبد الصمد**.

### 3. مصحح القراءة والتلاوة بالذكاء الاصطناعي (AI Recitation Checker)
* ميزة التسميع عبر الميكروفون المباشر.
* تحليل الصوت في الوقت الفعلي ومقارنته بالرسم القرآني.
* كشف الكلمات الصحيحة بالأخضر والأخطاء بالأحمر مع حساب نسبة الدقة (%100 ممتاز).
* زر للاستماع لنطق الشيخ المعتمد لتصحيح النطق فوراً.

### 4. وضع العرض والتسميع والحفظ (Memorization & Hifz Mode)
* **وضع إخفاء الكلمات (Blind Mode)**: تمويه الكلمات للتسميع الغيبي مع إمكانية النقر لكشف الكلمة للتذكير.
* **وضع رؤوس الآيات**: إظهار الكلمة الأولى من كل آية فقط للمساعدة على استحضار الآيات.

### 5. تجربة مستخدم عصرية وفاخرة
* **محرك بحث فوري** مع اختصار `Ctrl + K`.
* **مظهر متكيف**: وضع نهاري (Light)، وضع ورقي (Sepia)، ووضع ليلي (Dark).
* **تطبيق ويب تقدمي (PWA)**: قابل للتثبيت على الهاتف والحاسوب ويعمل في وضع عدم الاتصال (Offline Cache).

## 🚀 التشغيل المحلي (Getting Started)

### المتطلبات
* [Node.js](https://nodejs.org) (v18 فما فوق)
* npm أو pnpm أو bun

### التثبيت والتشغيل

```bash
# الانتقال لمجلد تطبيق الويب
cd web

# تثبيت الحزم
npm install

# تشغيل خادم التطوير
npm run dev
```

افتح المتصفح على: [http://localhost:3000](http://localhost:3000)

### بناء النسخة الإنتاجية (Production Build)

```bash
cd web
npm run build
```

تُحفظ الملفات الثابتة في مجلد `web/out`.

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **الإطار**: [Next.js 16](https://nextjs.org) (App Router + Turbopack)
* **اللغة**: TypeScript
* **التنسيق والتصميم**: Vanilla CSS + Tailwind CSS v4
* **الخطوط**: KFGQPC Warsh Uthmanic Font & Amiri
* **المكتبات الصوتية**: EveryAyah Quran Audio Data
* **التعرف الصوتي**: Web Speech API (ar-SA / ar-DZ)
